# Backend & admin

Medusa v2 backend for the craft store. See the README in the project root for setup.

- `src/modules/store-content` – banners, homepage sections, site settings
- `src/modules/razorpay` – Razorpay payment provider
- `src/api/store/content`, `src/api/admin/content` – API routes for the above
- `src/admin/routes/storefront` – the "Storefront" page in the admin panel
- `src/scripts/seed.ts` + `catalog.ts` – sample categories and products
